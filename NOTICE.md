# Attribution and external rights

Original English notes, workflows, build tooling and adapter code are provided under MIT. Clinical statements cite their underlying sources; the project does not claim ownership of external source content.

The 88-entry source register preserves links and actual reading limits from the earlier general medical knowledge edition. Modules and integration notes were translated and adapted for general distribution; individual installation locations/private storage identifiers were removed. See `docs/migration.md` for coverage.

No commercial textbook chapters, full GINA guide, paid interaction database, third-party model weights or DDInter CSV/database is included. A public link or searchable abstract is not a redistribution license.

Research notes describe external projects only. Their licenses apply separately: examples include DDInter CC BY-NC-SA 4.0 data, MedGemma HAI-DEF weights, Apache-2.0/MIT code and OpenEMR GPL code. A descriptive link does not sublicense those materials under MIT.

The package icon is an original vector book symbol. No Red Cross, medical-provider endorsement or regulator logo is used.
