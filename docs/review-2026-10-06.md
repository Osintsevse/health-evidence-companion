# Repository review for version 0.2.0

Review date: 2026-10-06 UTC (2026-10-07 in Belgrade). Baseline: public `main` commit `2cb9ac2627e1f8dbefd79988bc95b45b5578b357`. This is a content/source/packaging review, not clinician certification, clinical validation or platform approval.

## Scope

Reviewed canonical medical notes, six skill instructions and their UI metadata, source-register structure, five blank template files, policies/licence, contribution/migration/distribution documents, CI/release/security configuration, packaging/validation scripts and the optional DrugBank adapter/tests. Generated references are duplicate copies checked against canonical bytes; they are not additional independent literature.

The [access audit](source-access-audit-2026-10-06.json) covers all 88 original registered URLs and forty other documentation links. Seventy-five original URLs returned page metadata; thirteen had access errors/challenges. Metadata retrieval does not establish a full reading or current clinical accuracy. A failed research-tool lookup does not establish that a public site is broken. Repository access was independently confirmed with the authorized GitHub connection.

## Findings and corrections

| Finding | Change | Remaining limit |
|---|---|---|
| Allergy, labs and vaccination were brief introductory notes | New modules 15-17 with selected specialist/official sections, source versions and diagnostic limits | Not a complete specialist course or personal clinical assessment |
| Medicine workflow lacked a clear efficacy gate | Module 18 and skill instructions distinguish support, recommendations against, insufficient/uncertain evidence and pending appraisal | No exhaustive drug classification or guarantee against every erroneous answer |
| Supplied popular medicine lists contain broad/outdated claims | Use them only as discovery leads; check primary evidence and indication-specific exceptions | Many named candidates still need appraisal |
| NCCIH's Australian-review status was stale | Reference the government Natural Therapies Review 2024 report released in 2025, with its scope/uncertainty | Selected summary/methods read, not the entire report |
| Old review summaries can be mistaken for new evidence | Preserve publication/search dates and require update checks | A current retrieval date does not make a 2013-2015 review current |
| Some official labels/guidelines were inaccessible in this audit | Add explicit access limitations rather than reconfirm old dosing/registration | ALIMS historical examples require current local verification |
| Setup/validation docs still described GitHub as unverified future work | Correct public repository/initial CI status and explain artifacts, release assets and installation access | Tag release and ChatGPT publication remain separate unverified operations |
| Optional adapter tests were absent from CI | Run its eight offline mocked tests alongside packaging checks | SDK runtime, handshake and licensed provider calls remain untested |

The owner's merged checkout/upload-artifact updates are preserved. `CODEOWNERS` remains `@Osintsevse`; changes use a PR. The owner reported enabling branch protection; its settings were not independently fetched with the available connector. No administrative bypass or merge is performed as part of this review.

## Evidence expansion

The source register now has 128 entries, retaining S01-S88 and adding S89-S128. Three are clearly labelled secondary discovery lists. The new material covers:

- Sensitization versus allergy, history-directed tests, supervised challenges, rhinitis comparisons, emergency distinctions and the 2026 urticaria publication.
- Reference intervals versus diagnostic thresholds, CBC/differential, ferritin/inflammation, CRP, kidney chronicity, HbA1c interference, thyroid/biotin and liver/VTE pathway concepts.
- Selected Batut 2026 and Russian official calendar landmarks, the internally dated December 2025 WHO interrupted-schedule table and vaccine-specific contraindications.
- Homeopathy, bounded cold-treatment findings, WHO non-severe-influenza advice, Cerebrolysin outcome/harms, current adamantane resistance, and trimetazidine/piracetam indication distinctions.

Reading status is per source. Full 2026 urticaria treatment tables, complete national/legal calendar consolidation, many older-brand evidence bodies, textbooks and major specialty treatment pathways remain unfinished. No individual medical data or supplied medical images were used or converted into general examples.
