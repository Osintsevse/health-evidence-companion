## Repairs and retention

The source-use policy names providers with explicit AI/compilation restrictions, separates old bibliographic history from permission, and is shipped with health references and source attribution. New pediatric clinical paragraphs, routes and fixtures were rebuilt from independent usable primary sources; unsupported precise rules were removed. A machine guard rejects restricted providers as active evidence in the three new pediatric topics, including references hidden only in routes or fixtures. Source selection during an arbitrary live chat is still instruction-driven; there is no guaranteed network filter.

[Public JSON evidence](../evals/pediatrics-under-five/response-samples.json) retains fourteen raw responses. Six excluded clinical outputs retain only prompts, URL failure metadata and parent observations, rather than republishing restricted derived content. These failures are not erased or mislabeled as successes. The raw before-correction responses also show the wording that motivated repair.

An independent agent reviewed the three module texts/navigation and selected important primary sources. The initial bounded review found no confirmed new content error; source-rights review subsequently led to corrections. It did not appraise every full text, whole legacy corpus, national calendar or clinical outcome. Final parent review checked the corrected text and actual response samples. All 214 reusable fixtures, including 49 new pediatric fixtures, remain explicitly unexecuted and are not counted as these twenty responses.

Citation placement in these few answers was inspected selectively, not measured as a citation-accuracy benchmark. For example, F1 used the correct young-infant fever threshold from the reference material but could have linked its exact supporting fever page more directly.

No real-child triage performance, exam/photo accuracy, pediatric prescription calculation, clinic availability, remote storage operation, host installation, complete national calendar coverage or independently credentialed clinical review is established.
