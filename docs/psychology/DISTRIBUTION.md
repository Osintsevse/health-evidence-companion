# Installation and sharing

## ChatGPT Project

Download and extract the ChatGPT Project ZIP from Releases. Create a separate project, upload PROJECT_KNOWLEDGE.md and SOURCE_REGISTER.json, and copy PROJECT_INSTRUCTIONS.md into its instructions. START_HERE.md gives the steps. The materials are in English; conversation follows the user's language or explicit language preference. A GitHub URL alone does not install a plugin or create a Project.

Share the general project files as needed. Add personal journals, results and private links only in a separate private context, with the owner's authorization. Written instructions do not create technical memory isolation: check the project and service settings separately. Do not promise automatic Google Drive access.

Reference: [official Projects documentation](https://learn.chatgpt.com/docs/projects).

## Plugin and skills

The plugin ZIP contains a manifest and six self-contained skills with references. Use the manual installation or upload route supported by your account, or a GitHub marketplace workflow. Availability depends on the environment and its policies. A GitHub release does not imply publication in OpenAI's public directory or automatic updates to an installed copy.

The individual skill folders can also be used as Codex skills. They contain generated references and require no personal archive. The package adds no MCP server, API key, paid provider or hidden backend.

Reference: [official plugin packaging documentation](https://developers.openai.com/plugins/build/plugins).

## Updating

Edit canonical knowledge and SKILL.md files in English. Preserve the user-language conversation rule. Synchronize references and the Project edition; check the explicit file allowlist, links, versions, blank forms and ZIP contents; then release a new version. Update manually installed copies separately. No background literature monitoring is configured.
