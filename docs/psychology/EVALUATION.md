# Behavior Assessment

The public examples are in English. Runtime language selection follows the user's current language or explicit preference in all six skills and Project instructions. Independent multilingual behavior testing has not been performed; package checks verify that these rules remain present.

evals/response-samples.json contains 12 completely synthetic queries and editorial responses from the current assistant. The answers were self-reviewed by that assistant according to the specified criterion. This is not an independent run of each skill, nor a model comparison, nor a professional assessment, nor a clinical review.

Areas: exercise refusal, assent, reassurance, MCT, acceptance/violence, driving, malfunction, possible concussion, shared privacy, current danger, personal case publication, statistical equivalence.

The next independent test should only receive the request corresponding to the skill and the relevant synthetic context, without these answers and the expected result. Evaluate observed benefit, respect for the request, precision/uncertainty, safety, privacy, and ability to correct. An unsafe answer requires correction, and the average score does not hide a critical error. After the change, repeat the affected situations; long-term care and transfer to the individual remain separate studies.

Automatic checks in scripts/validate.py check composition, links, empty forms and synchronization. Their success does not mean the truth of psychological statements. External peer/clinical evaluation of the public version has not yet been conducted.
