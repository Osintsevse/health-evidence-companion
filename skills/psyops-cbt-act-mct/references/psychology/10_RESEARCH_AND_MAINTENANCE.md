# Organization and expansion of the common base
Version 2.0 · 2026-09-28

## Knowledge Repository
The input skill contains short routing and mandatory boundaries. Thematic Markdown files contain explanations and practices; sources.json is a machine-readable registry, SOURCES.md is its readable version. Personal profiles and collaborative journals live outside the overall package.

Load only relevant material. A full corpus is not needed for every question. For new clinical recommendations, check current primary/official sources; Do not send personal details in search queries.

## Recording knowledge
ID; Name; date of publication and review; URL/DOI; source type; level of access actually obtained; population/indication; comparison; outcome/term; what is supported; restrictions; practical application. Mark missing data as unknown, do not invent missing details.

The guide helps you choose a practice; RCT evaluates a specific comparison; the code describes the responsibilities; A skill README describes its design. These are different types of evidence. Meta-analysis is not automatically more reliable than a high-quality RCT: composition, risk of bias, and relevance to the question are important. Do not count republications of the same trial as independent confirmation.

## Adding new topics
1. Formulate a practical question without personal details.
2. Find specialized recommendations, reviews and necessary primary work.
3. Record actual access and limits on applicability to AI.
4. Add a small topic document and a link from the router.
5. Test dangerous interpretations using synthetic examples.
6. Update version date and history; Update the skill snapshot separately.

Just because a new topic is mentioned in a conversation does not mean that it has been researched or that a new clinical protocol can be started. Do not copy other people's programs and worksheets without the terms of the license.

## Versions and saving
Corrections - 2.0.1; new themes - 2.1; significant change in behavior - 3.0. Before replacing, read the current document and maintain its identity if it is an update. Package transfer exception: If the original file had a personal history, create a cleaned new file instead of distributing older versions.

The change history should include the cause, sources, and impact on behavior. Changing the shared folder does not automatically update embedded links and skill snapshots. The skill is saved by the standard installation mechanism and is checked after saving.

## Quality control
- Links [Sxx] exist; the conclusion relates to the desired population and comparison.
- Editorial ratings are not designated as GRADE.
- Self-help is not called a full-fledged treatment.
- The general block does not contain personal data or links to personal archives.
- There are no diagnoses for absent people, no hidden coalition and no promises of guaranteed results.
- Examples test natural storytelling without a school choice command, boundaries of consent, risk, and context transfer.

## Relevance and limitations
This is a targeted review and not a systematic review with independent duplicate screening. Some works are available only as abstracts or indexed excerpts; this is reflected in the register. The number of source records is not equal to the number of independent studies.

Re-check medical claims before significant new use; codes when changing editions; AI products before choosing them. Scheduled revisions can be performed upon request. Background updating and user monitoring are not configured and are not promised.
