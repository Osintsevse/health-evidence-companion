# PsyOps - common base
Public version 0.1.1 · base 3.0 · 2026-10-08

Universal knowledge, methods, ethics, risks and original practices for psychological self-exploration of adults. There are no personal profiles, stories or links to personal journals in this block.

## How to use
Describe the situation in ordinary words. The assistant selects the format and preliminary approach according to 16_AUTO_ROUTING.md without requiring the name of the method. For an overview of directions read 01_EVIDENCE_MAP.md and 15_MODERN_APPROACHES.md; for a joint conversation - 17–19; for cultural applicability - 22; for new data on AI - 09; for sports psychology and races - 23–25.

The map has 25 positions: schools, families and protocols, and not a single rating. There are 102 sources in the registry, which does not mean 102 independent trials. There are 24 original cards, 8 new motorsport practices and a separate preventive pair template. The level of access actually read is indicated on each entry.

The PsyOps dialogue skill provides a stand-alone snapshot of the overall methodology. It doesn't require anyone else's profile and doesn't inherit anyone else's personal preferences. Materials can be expanded by checking sources and boundaries.

## Transfer and restrictions
Only this common block or common skill is intended to be transferred. Do not transfer parent folders with personal data. The rules are in 21_SHARING_GUIDE.md. Access rights were not automatically changed.

This is an advanced targeted review and work instructions, not a psychologist's training, licensure, or clinically proven treatment through AI. The novelty of a method does not prove superiority. The use of a skill depends on its availability in a particular environment; The other application's settings are not automatically changed.
