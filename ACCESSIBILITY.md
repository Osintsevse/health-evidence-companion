# Accessibility

## Commitment and scope

Health Evidence Companion aims to make its general health and adult psychology material understandable and usable by people with different communication and access needs. This statement covers repository documentation, distributed text-based skills and optional generated archive views. It is not an accessibility certification.

## Ways to use the material

- Read Markdown documentation on GitHub or in a compatible local text reader.
- Use the text-based skills in a host that supports their installation and execution; see [platform setup](docs/platforms.md).
- Ask the assistant for shorter explanations, step-by-step text, defined terms or a response in your language. Source package content is English; translated responses depend on the host model and may contain errors.
- For an optional private archive view, ask for a source-linked text or table alternative to a chart when authorized tools and the underlying data are available.

Keyboard navigation, screen-reader behaviour, zoom, contrast and voice input depend partly on the chosen host, browser, reader and operating system. No supported assistive-technology matrix has been verified.

## Known limitations

No formal WCAG conformance assessment or systematic screen-reader, keyboard-only, contrast or zoom audit has been completed for the project. Optional HTML archive views and charts may have barriers; the existence of a table or text workflow does not establish equivalent access for every chart.

Scanned PDFs, photographs, handwritten records, complex tables and genetic-provider exports may need extraction or human clarification. Unreadable content must remain uncertain rather than be invented. OCR availability and accuracy depend on separately authorized tools. AI responses may be inaccurate or unnecessarily complex; requesting a different format does not establish clinical reliability.

External source websites, GitHub and host applications control their own accessibility. This project cannot guarantee their behaviour.

## Report a barrier

Open a [general issue](https://github.com/Osintsevse/health-evidence-companion/issues/new/choose) with:

- The public documentation path or feature affected.
- The task you were trying to complete and what prevented it.
- Relevant host, browser or reader versions and assistive technology, if you choose to share them.
- The format or interaction that would help.

Do not include real medical or psychological records, private archive URLs, credentials or screenshots/logs containing personal information. Reproduce the problem with wholly fictional data labelled synthetic. For sensitive disclosures, follow [SECURITY.md](SECURITY.md).

The maintainer reviews reports as capacity allows; no fixed response or remediation time is promised. Accessibility improvements should be verified in the affected interaction before being described as supported.
